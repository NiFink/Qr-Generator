# Qr-Generator
Small Application to generate Qr-Codes with Image in it.

## Projekt starten

1. Entzippe den Ordner und verschiebe ihn an einen Ort mit ausreichend Speicherplatz.
2. Öffne den entpackten Ordner im Explorer. Klicke in die Pfadleiste (siehe Video), gib **`cmd`** ein und drücke **Enter**.
3. Gib im geöffneten Fenster den folgenden Befehl ein und bestätige mit **Enter**:

   ```
   npm i
   ```
4. Starte anschließend das Projekt mit:

   ```
   npm run dev
   ```
5. Nach dem Start wird ein Link mit **`localhost`** angezeigt. Halte **Strg** gedrückt und klicke auf den Link – alternativ kannst du ihn kopieren und in deinem Browser öffnen.
